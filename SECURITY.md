# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this extension, please report it
privately to **security@williamjacoby.cc** rather than opening a public issue.

Please include:

- The organization name (**phpbbmodders**) and repository name
  (**phpbb-ext-wiki**).
- A description of the vulnerability and steps to reproduce it.
- The phpBB version(s) and PHP version you tested against.

We'll acknowledge your report and work with you on a fix and coordinated
disclosure timeline.
